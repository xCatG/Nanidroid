## Gates and scope

The wrapper JVM test command, lint/debug APK command and connected command completed with exit 0. The XML reports 115 JVM tests, 2 skipped, zero failures/errors; the connected XML reports 41 tests, 22 skipped, zero failures/errors. Fixture tests in the broad connected invocation skip without host staging arguments; the separate targeted script completed 12 one-test instrumentation invocations plus the intentionally interrupted write phase. Its logs are the persistence gate, not the broad suite's green status alone. Arm64 execution remains untested because no arm64 device was available.

One intermediate connected rerun aborted when Android's activity/package services crashed during `GhostStageTest`; its XML was incomplete and is not counted above. After the emulator reported boot complete, both APKs were reinstalled, all 10 `GhostStageTest` cases passed in a focused rerun, and the full connected command then passed with the counts above. The transient failure and recovery were device-state evidence, not a product fix.

The [LOBO rendering reproduction](testing/lobo-rendering-reproduction.md) is separate. The observed fallback is assigned to milestone four; the user's exact missing part still needs identification. Import milestone three must reject overwriting an existing ghost by default or adopt a separately designed save-preserving policy. Milestones three through five remain outstanding, and this checkpoint does not claim full native or application compatibility.
