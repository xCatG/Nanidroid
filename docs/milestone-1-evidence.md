A test-only `ShioriEngine` decorator records requests and status; it wraps the actual `BuiltInShiori` loaded from that archive. One Compose touch at rendered kero's center produced exactly one `OnMouseClick` with references `117, 100, 0, 1, "", 0, touch` (unscaled 235 × 200 surface center), status 204, and no new text or balloon. No product event-log UI or invented ghost response was added. Existing ActivityScenario tests cover loading recreation, mid-dialogue recreation, and portrait-to-landscape rotation with no duplicate first boot and continued text. The screenshots and layout dumps are direct normal-APK observations; event and rotation-continuity assertions are connected-test evidence.

This is evidence for the bundled Kotlin-engine walking skeleton on one emulator. It does not establish native-engine integration, general ghost compatibility, or a broad device matrix.
